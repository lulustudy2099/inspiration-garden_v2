# 🌱 灵感花园

把一闪而过的念头种进小花园：写下一句话，挑个位置种下嫩芽；有了跟进，它长成花苞；做出成果，它就开花。支持照片、语音、自定义标签，灵感和每条生长记录都可以修改、删除。花会轻轻摇摆，十天没照看还会有点蔫，点开就能唤醒。

这是可以直接放在 **GitHub Pages** 的网页版，手机浏览器打开，也能添加到 iPhone 主屏幕。无需安装 Node.js、数据库或服务器。

## 上传，开花

1. 在 GitHub 新建 **Public** 仓库，例如 `inspiration-garden`。
2. 解压本包，把**解压后里面的文件**（`index.html`、`app.js`、`style.css`、`assets/`、`.nojekyll` 等）上传到仓库**根目录**。在 GitHub 仓库点 **Add file → Upload files**；不要把外层文件夹作为唯一内容上传。
3. 在仓库 **Settings → Pages** 选择 **Deploy from a branch**，分支 `main`、目录 `/(root)`，保存。稍等几分钟，打开显示的地址，例如 `https://你的用户名.github.io/inspiration-garden/`。
4. 把网址发给朋友。iPhone 用 Safari 打开，点分享 → **添加到主屏幕**。

更新版本时，上传新文件并覆盖旧文件即可。若手机仍显示旧页面，关掉页面再打开；必要时清除这个站点的缓存。GitHub Pages 在不同网络下速度可能不同。

## 我的灵感存在哪里？

每个人的数据存在**自己设备的浏览器里**：灵感、照片、语音放在这个网址对应的 IndexedDB；标签放在同一网址对应的浏览器存储中。GitHub 只托管网页文件，**不会保存大家写的灵感，也不会自动同步到其他手机**。朋友打开同一网址，看见的是各自的花园。

在「灵感手记」点 **导出备份**，会下载一个 JSON 文件，里面包含文字、标签、位置、照片和语音。换手机或浏览器后，在新设备打开同一网站，点 **导入备份**。建议定期备份，并把 JSON 私下保管：它包含你的私人记录，**不要上传到公开的 GitHub 仓库**。清除网站数据、浏览器隐私模式、换设备，或改用另一个域名，都不会自动带走原数据。若沿用原来的 GitHub Pages 网址，旧版存在同一浏览器的灵感会继续保留。不同网址的数据不会自动迁移。尤其是之前的 ChatGPT 私人预览版使用服务器存储，目前没有导出入口，记录**不会**跟随这个压缩包；若以后要迁移，需要先为那个版本单独增加导出功能。

本地查看：在本目录运行 `python3 -m http.server 8000`，浏览器打开 `http://localhost:8000/`。公开网页使用 HTTPS，才能正常请求麦克风权限。
