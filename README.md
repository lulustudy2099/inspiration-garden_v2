# 🌱 灵感花园
把一闪而过的念头种进花园，说不定哪天就会开出意想不到的花！🌼

你是否也有过许多突然的灵感？

搭建一个属于自己的网站？
一个或许可行的游戏创意？
DIY一件小手工？
或是藏着一些大大小小的愿望和期待……

可惜，很多灵感只是一闪而过，还没来得及实现，就悄悄被遗忘了。

但谁说一个小小的念头，不能长成了不起的东西呢？

在「灵感花园」，每一个想法都可以成为一颗种子。

把它种下来，记得常来看看，给它一点行动的养分，记录它一点一滴的成长。

也许就在不久后的某一天，你会惊喜地发现：当初随手种下的小种子，竟然真的开花啦！🌷

## 使用指南
复制网址：
https://lulustudy2099.github.io/inspiration-garden_v2/
iPhone 用 Safari 打开，点分享 → **添加到主屏幕**。

更新版本时，上传新文件并覆盖旧文件即可。若手机仍显示旧页面，关掉页面再打开；必要时清除这个站点的缓存。

## 我的灵感存在哪里？

每个人的数据存在**自己设备的浏览器里**：灵感、照片、语音放在这个网址对应的 IndexedD。

在「灵感手记」点 **导出备份**，会下载一个 JSON 文件，里面包含文字、标签、位置、照片和语音。换手机或浏览器后，在新设备打开同一网站，点 **导入备份**。建议定期备份，并把 JSON 私下保管，它包含你的私人记录。清除网站数据、浏览器隐私模式、换设备，或改用另一个域名，都不会自动带走原数据。若沿用原来的 GitHub Pages 网址，旧版存在同一浏览器的灵感会继续保留。不同网址的数据不会自动迁移。
公开网页使用 HTTPS，才能正常请求麦克风权限。
